# The LGL Wallpaper Collection

A curated personal wallpaper collection prepared for a 3440×1440 ultrawide display.

---

## Overview

The LGL Wallpaper Collection brings together landscapes, science fiction, digital art, photography, and abstract backgrounds in one consistently formatted library.

- Every tracked wallpaper is prepared at 3440×1440
- Images are centred and scaled to fill a 21:9 ultrawide display
- Files use a simple sequential numbering scheme
- Original source files and locally retained `vect_*` images are excluded from Git

---

## Get the Collection

```bash
git clone git@github.com:linuxgamerlife/Wallpapers.git
cd Wallpapers
```

Select the cloned folder as your wallpaper source in your desktop environment's appearance settings.

---

## Collection Details

| Property | Details |
|---|---|
| Target resolution | 3440×1440 |
| Aspect ratio | 21:9 ultrawide |
| Formats | JPEG, PNG and WebP |
| Naming | Sequential four-digit filenames |
| Scaling | High-quality Lanczos resampling |
| Framing | Centred, full-screen crops |
